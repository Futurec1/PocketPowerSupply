## Project Overview

The Pocket Power Supply is a versitile, multi-rail, mobile DC power supply. It can accept a wide range of DC power sources (USBC PD/PPS/non-PD, internal battery, external jack), and output a fixed 3.3V, a fixed 5V, and 2 adjustable output rails. it is meant to be a convienient prototyping tool, makeshift power supply, and a low-power UPS. A jack of all trades, master of none, but hella conveneint.

## Educational Value Added

Advanced soldering, Power management (safety, battery charging, power ORing, DCDC conversion, varying power input and outputs), Embedded Systems (embedded MCU with peripherals, making IC's interact with each other), thermal management, Schematic design, hardware/software debugging

Phase I - PCB with 3V3 & 5V DCDC converters, USBC PD integration, and ideal diodes (a bypass for the 5V DCDC converter when Vin is 5V)
Phase II - PCB with Phase I components, along with an embedded MCU, two adjustable DCDC converters, and power ORing between USBC and an external input. Modular for prototyping.
Phase III - PCB with Phase II components, along with batteries & charging, a smaller footprint, a function generator, and a LED/Motor driver

## Design Decisions
The project will have 3 phases, Phase I to Phase III. Each phase is meant to provide experience for the next phase, as well as prototyping to work out kinks in the design.
